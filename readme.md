## 怎么做的

每一只都是一个单独的 HTML 文件：图形是内联 SVG，声音是 Web Audio 现场合成的，没有图片、没有外部依赖，复制到哪儿都不会白屏，断网也能开。

## 更新

在电脑上双击 `发布.bat`，它会把这个仓库里最新的捏捏乐同步过来，然后推上去。
